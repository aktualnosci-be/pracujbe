# Organiczne materiały marki

Ten katalog zawiera gotowe, całoroczne materiały do bezpłatnej publikacji na
własnych profilach Pracuj.be. Nie jest planem kampanii, reklamą płatną ani
obietnicą emisji, zasięgu lub wyniku.

## Story PL: profil zawodowy

- `pl/profile-story-1080x1920.svg` jest samowystarczalnym źródłem 1080 × 1920 px.
- `pl/profile-story-1080x1920.png` jest deterministycznym eksportem do publikacji.
- Materiał nie zawiera zdjęć, zewnętrznych odwołań ani zależności od fontów.
- Docelowy adres po publikacji: `/pl/rejestracja`.
- Zatwierdzony tekst alternatywny dla PNG: „Grafika Pracuj.be: Pokaż, co
  potrafisz. Stwórz swój profil zawodowy bez układania CV.”
- Treść jest zatwierdzona wyłącznie dla wersji polskiej. Inne języki wymagają
  osobnego zatwierdzenia tekstu.

PNG odtwarza polecenie:

```bash
node scripts/generate-organic-story.mjs
```
